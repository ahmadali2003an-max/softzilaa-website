✅ IMAGE REPLACE KARNE KA TARIKA
------------------------------------------------------------

STEP 1: Apni image teyar karein
  - Recommended formats: JPG, PNG, WebP, SVG
  - Logo ke liye: PNG with transparent background (200x60px)
  - Portfolio images: 800x500px ya 16:9 ratio
  - Team photos: 400x400px (square/circle crop)
  - Client logos: 200x80px (transparent background)

STEP 2: File rename karein
  - Apni image file ko same naam dein jis SVG ko replace karna hai
  - Example: apni company logo ko "logo.png" naam dein

STEP 3: Old file replace karein
  - Purani .svg file delete karein
  - Apni nayi image file wahan paste karein

STEP 4: HTML mein path update karein (agar different format)
  - Agar aap .jpg ya .png use kar rahe hain, to HTML mein src update karein
  - Example: src="/assets/images/logo.svg" → src="/assets/images/logo.png"

💡 TIPS
------------------------------------------------------------

  1. Logo transparent PNG recommended hai (background na ho)
  2. Portfolio images zyada acha dikhengi agar same size rakhein
  3. Team photos square (1:1) recommended hain
  4. Client logos white ya light color mein best dikhte hain
     (dark background pe)
  5. WebP format use karein zyada fast loading ke liye
